# Contributing to ShopKill Core

Thank you for considering contributing to ShopKill Core.

## Guidelines

1. **Code Standards**:
   - Write clean, modern SourcePawn (`#pragma newdecls required` or modern conventions).
   - Use block comments (`/* ... */`) for code commentary.
   - Avoid decorative divider lines in comments.

2. **Commit Messages**:
   - Follow Conventional Commits format (`feat:`, `fix:`, `refactor:`, `docs:`, `chore:`).
   - Write clear imperative descriptions of changes.

3. **Submitting Changes**:
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/my-improvement`).
   - Test compilation with SourcePawn 1.11 / 1.12 before opening a pull request.
   - Submit your pull request with a clear description of changes.
